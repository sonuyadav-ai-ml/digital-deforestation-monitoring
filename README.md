# ForestWatch AI — Version 2
## Digital Monitoring of Deforestation Using Satellite Images

### What this version demonstrates
1. Product-style ForestWatch AI dashboard
2. Satellite monitoring workspace
3. Upload your own satellite/forest image
4. Before/after change visualization
5. NDVI-style vegetation change metrics
6. AI classification: natural change vs true deforestation
7. Risk score and confidence
8. Detection evidence
9. Priority alert center
10. Evidence/report generation and TXT download
11. Large-screen/projector friendly UI

### Run
Extract the ZIP and open `index.html` in Chrome/Edge. For the smoothest VS Code demo, use Live Server.

### Important
This is a front-end academic prototype. The displayed satellite measurements and AI classification are simulated. A production system would connect real Sentinel-2/Landsat data, geospatial preprocessing, NDVI calculation, a trained model, and a GIS/map backend.

### Suggested live-demo flow
Dashboard → Launch Satellite Monitor → upload an image → Run AI Scan → AI Analysis → Risk Alerts → Reports → Download Report.
